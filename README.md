# Campus Placement AI

AI System for Placements

## Features
- Resume Parser
- Student Management
- Job Matching

## Tech Stack
- FastAPI
- SQLAlchemy
- SQLite
- Python

## How to Run
1. Create virtual environment
2. Install requirements
3. Run: uvicorn backend.app.main:app --reload
4. Open: http://localhost:8000/docs
